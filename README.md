# Banquet Drinks Ordering System

A GitHub Pages-compatible static version of the banquet drinks ordering tool.

## Features

- Add banquet tables with chair counts
- Seat 1 is treated as the head of each table
- Clickable room-plan grid for placing and moving tables
- Section creation through setup/table assignment
- Server assignment per table
- Seat-by-seat drinks and notes
- Bar prep screen grouped table-by-table
- Per-seat and per-table ready statuses
- Completion notification when a table is marked ready
- Extra confirmation before deleting a table

## GitHub Pages deployment

Upload the contents of this folder to the root of your GitHub repository, then enable:

`Settings → Pages → Deploy from branch → main → /root`

This is a browser-only app. Data is saved in localStorage on the device/browser being used.
